## The confession

> Confession: I don't say 'Great question!' because it is one — I say it to buy time while I figure out what you actually asked.

## How it works

`main.py` (Python 3, standard library only) prints exactly that one line
and writes it to `/output/entry.txt`, the path the make.fun gate scorer
reads. The line is 126 characters, a single line, deterministic on every
run.

Run it:

```sh
python3 main.py
```
